# AI QUEST

8ビット風の世界観で、回答から自分に合うAIを診断する静的Webゲームです。

## 起動方法

Node.jsやビルドツールは必要ありません。リポジトリのルートで次を実行してください。

```bash
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000/> を開きます。

`file://` で直接開くと、ブラウザの制限により音声などが正しく動作しない場合があります。

## GitHub Pagesで公開する場合

1. GitHubリポジトリの **Settings > Pages** を開く
2. **Deploy from a branch** を選ぶ
3. 公開するブランチのルート（`/(root)`）を選んで保存する

ビルド手順は不要です。`index.html` が公開ページの入口になります。

## 構成

- `index.html` — ゲーム画面と操作要素
- `app.js` — 診断の分岐・採点・音声・結果画面
- `style.css` — 8ビット風の画面デザインとレスポンシブ対応
- `assets/images/` — タイトルロゴ、城内背景、キャラクター、玉座、転移ゲート、RPG風UIのオリジナルSVG素材

## 注意

診断はブラウザ内で完結するルールベースの処理です。回答を外部サーバーへ送信しません。

画像素材は外部CDNを使わず、すべてリポジトリ内のSVGとして読み込みます。
