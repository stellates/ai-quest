# AI QUEST

8ビット風の世界観で、王さまから遊びのプロンプトを受け取り、無料AIサービスへ旅立つ静的Webゲームです。

## 起動方法

Node.jsやビルドツールは必要ありません。リポジトリのルートで次を実行してください。

```bash
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000/> を開きます。

`file://` で直接開くと、ブラウザの制限により音声などが正しく動作しない場合があります。

## GitHub Pagesで公開する場合

1. GitHubリポジトリの **Settings > Pages** を開く
2. **Deploy from a branch** を選ぶ
3. 公開するブランチのルート（`/(root)`）を選んで保存する

ビルド手順は不要です。`index.html` が公開ページの入口になります。

## 構成

- `index.html` — ゲーム画面と操作要素
- `app.js` — 王さまの会話・ランダムなお題/AIサービス選定・周回履歴・遷移・音声
- `style.css` — 8ビット風の画面デザインとレスポンシブ対応
- `assets/images/` — タイトルロゴ、城内背景、キャラクター、玉座、転移ゲート、RPG風UIのオリジナルSVG素材

## ランダム選定と周回

遊びのプロンプトは33パターン、AIサービスは次の3候補からランダムに選びます。AIサービスは3候補を公平に抽選します。勇者の名前に「猫」や「プリン」などのお題に関係する語が含まれる場合だけ、対応するプロンプトの重みが少し上がります。勇者の性別はスプライト表示にだけ使い、抽選には使いません。

直前のサービス1件と、直近3件のプロンプトは `localStorage` の `aiQuestHistoryV1` に保存し、次の抽選から一時的に外します。保存する形は次の最小構成です。

```js
{
  recentServices: [],
  recentPrompts: []
}
```

結果画面の「もう一度 王さまに引いてもらう」は名前と性別を維持したまま、AIサービスとお題だけを引き直します。「最初からやり直す」はタイトルへ戻り、名前と性別を初期化します。

## サービス条件

- ChatGPT — 無料・対応地域ではアカウント作成前の利用が公式に案内されています。<https://help.openai.com/en/articles/9125172>
- Gemini — 一部機能をログインなしで使えることが公式に案内されています。地域・端末・機能による制限があります。<https://support.google.com/gemini/answer/13275745>
- Copilot — 無料版はサインイン不要で使えることが公式に案内されています。<https://support.microsoft.com/en-us/topic/understanding-the-different-microsoft-copilot-experiences-cfff4791-694a-4d90-9c9c-1eb3fb28e842>

現在の対象AIは ChatGPT / Gemini / Copilot の3サービスです。各サービスの未ログイン利用可否や無料枠、利用上限は地域・端末・時期などで変わる可能性があります。AI QUESTは各サービスの利用可否を保証しません。

## テキスト遊び限定

現在のAI QUESTは、テキストプロンプトをコピーしてAIと遊ぶ用途に限定しています。画像・音楽・動画生成は対象外です。危険行為、違法行為、他者への嫌がらせ、アカウント停止につながりうる内容もお遊びプロンプトの候補から除外しています。プロンプトは結果画面に表示され、コピーして選ばれたサービスを別タブで開けます。名前などの入力はブラウザ内だけで扱い、ゲームから外部サーバーへ送信しません。

### Future Ideas

将来メディア生成に対応する場合は、通常のテキストお題とは別テーブル・別ルートに分けます。王さまの追加質問で利用意向を確認し、「はい」の場合だけ画像・音楽・動画用ルートへ進む想定です。今回は実装しません。

画像素材は外部CDNを使わず、すべてリポジトリ内のSVGとして読み込みます。
