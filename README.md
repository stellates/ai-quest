# AI QUEST

8bit RPG風の世界観で、王さまからランダムな遊び用テキストプロンプトを受け取り、ユーザーが選んだ主要AIサービスで試す静的Webゲームです。AI QUEST自体は外部AI APIを利用せず、AIサービスを自動選択したり、利用可否を判定したりしません。

## 起動方法

Node.jsやビルドツールは必要ありません。リポジトリのルートで次を実行してください。

```bash
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000/> を開きます。

`file://` で直接開くと、ブラウザの制限により音声などが正しく動作しない場合があります。

## GitHub Pagesで公開する場合

1. GitHubリポジトリの **Settings > Pages** を開く
2. **Deploy from a branch** を選ぶ
3. 公開するブランチのルート（`/(root)`）を選んで保存する

ビルド手順は不要です。`index.html` が公開ページの入口になります。

## 遊び方

1. 主人公の表示タイプと名前を選ぶ
2. AIの相棒として使うサービスを、次の5つから明示的に選ぶ
   - ChatGPT
   - Gemini
   - Copilot
   - Claude
   - Grok
3. 王さまから、`app.js` の `prompts` 配列に収録された14件のお題から1件を受け取る
4. 結果画面でプロンプトをコピーするか、選択したAIサービスを新しいタブで開く

「もう一度引く」では、選択済みのAIサービスを維持したまま、プロンプトだけを引き直します。「AIを変更」からサービスを変更できます。「最初から」ではタイトルへ戻り、名前・主人公の表示タイプ・選択サービス・選択プロンプトを初期化します。

プロンプトは直近3件を一時的に抽選対象から外します。名前にお題に関連する語が含まれる場合は、該当するプロンプトが少し出やすくなることがあります。これは遊びのためのプロンプト抽選であり、ユーザーやサービスを判定する仕組みではありません。

## 構成

- `index.html` — ゲーム画面と操作要素
- `app.js` — 王さまの会話、サービス選択、プロンプト抽選、ブラウザ内履歴、遷移、音声
- `style.css` — 8bit RPG風の画面デザインとレスポンシブ対応
- `assets/images/` — タイトルロゴ、背景、キャラクター、オブジェクトなどのオリジナルSVG素材
- `assets/audio/` — ゲーム内で使うローカル音源
- `THIRD_PARTY_ASSETS.md` — 第三者音源の出典・ライセンス記録

## AIサービスの利用条件

現在選択できるサービスは [ChatGPT](https://chatgpt.com/)、[Gemini](https://gemini.google.com/)、[Copilot](https://copilot.com/)、[Claude](https://claude.ai/)、[Grok](https://grok.com/) です。

AI QUESTは各サービスの利用可否、無料枠、ログイン要否、機能、利用上限などを保証しません。これらの条件はサービス提供元、地域、端末、アカウント、時期などによって異なり、変更される可能性があります。利用時点の各サービス公式案内を確認してください。

AI QUESTはプロンプトをコピーし、選択したサービスのページを開くだけです。AI QUESTから外部AI APIを呼び出したり、ユーザーの名前などを外部サーバーへ送信したりしません。各サービス上でユーザーが入力・送信する情報の扱いは、各サービスの規約・プライバシー方針に従います。

## テキスト遊び限定

AI QUESTはテキストプロンプトをコピーして遊ぶ用途に限定しています。画像・音楽・動画生成は対象外です。名前などの入力とプロンプト履歴はブラウザ内だけで扱います。

外部CDNや不要な依存関係は使わず、静的ファイルとして動作します。
